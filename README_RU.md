# SAFIA · Заявки посуды — Render

Версия 3.0. Интерфейс 2.3 сохранён: заявки с первого и третьего этажей, второй этаж — диспетчерская, без входа и назначения раннера. Диспетчер нажимает «Принял», затем «Отправил». Посуда, контрастные бежевые карточки и размеры кнопок сохранены.

## Публикация

Код для Render находится в ветке `render-app`. В корне есть `render.yaml`: Node.js Web Service и отдельная постоянная PostgreSQL-база в Frankfurt.

1. Через Render подключите этот репозиторий и ветку `render-app`.
2. Сборка: `npm ci --include=dev && npm run check && npm test && npm run build`.
3. Запуск: `npm start`.
4. Переменная `DATABASE_URL`: Internal Database URL базы в том же регионе и пространстве Render. Не публикуйте её в коде.
5. Node.js: 22; `NODE_ENV=production`. Порт берётся из `PORT`, сервер слушает `0.0.0.0`.
6. Проверка доступности: `/health`.

Миграции автоматически применяются при запуске сервера, в транзакции с блокировкой. Повторные запуски сохраняют заявки и настройки. На локальном диске сервера данные не сохраняются — используется PostgreSQL.

Файл `render.yaml` также позволяет создать ресурсы через New → Blueprint. Не применяйте его поверх уже созданных ресурсов без проверки имён и настроек: обычный запуск через подключённый репозиторий не создаёт автоматически управляемый Blueprint.

## Тариф

Выбран постоянный вариант: Web Service `0.5c-512mb` и Postgres `0.1c-256mb`, 1 ГБ хранения. Ориентир по ценам Render на 30 октября 2026 — $13,30 в месяц, без возможных налогов и превышения включённых лимитов. Актуальная сумма отображается в Render.

## Моноблоки

Все устройства открывают один опубликованный адрес Render. На первом выбирают «1-й этаж» и зону; на третьем — «3-й этаж» и зону; на втором — «Диспетчерская». Звук включается значком один раз на нужном устройстве.

Вход открыт по ссылке, без логина и пароля, как было запрошено. Доступны также настройки.

## Данные при переходе

Render использует новую отдельную базу. История и изменённые настройки из Netlify автоматически не копируются. Старый сайт и его база не удаляются. Для переноса существующих записей нужен отдельный экспорт и импорт перед переключением моноблоков.

## Локальный запуск

Node.js 22.14+ и PostgreSQL. Задайте `DATABASE_URL` в окружении, затем:

```sh
npm ci --include=dev
npm run check
npm test
npm run build
npm start
```

`APP_ORIGIN` можно задать для собственного домена; на стандартном адресе Render используется автоматически заданный `RENDER_EXTERNAL_URL`.

## Проверки

TypeScript, сборка React и Node.js, тесты каталога, ограничений этажей, PostgreSQL, повторной отправки и версий. HTTP-тест проверяет создание заявки, её отображение другому устройству, «Принял» → «Отправил», историю и настройки.

Структура: `src/` — интерфейс; `server/` — HTTP-сервер и API; `migrations/` — SQL; `tests/` — проверки. `dist/` и `dist-server/` создаются при сборке.
